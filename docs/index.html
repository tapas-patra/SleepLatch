macOS utility

Keep your Mac awake on purpose, not by accident.

SleepLatch is a lightweight menu bar app for timed keep-awake sessions, safer untimed sessions, and cleanup of stray caffeinate processes.

Download SleepLatch View Source

Download: zipped macOS app bundle (.zip) | Install by unzipping and moving SleepLatch.app to Applications.

What it solves
  • Timed keep-awake presets for 15m, 30m, and 1h
  • Live flag controls for idle, display, disk, and AC-only system sleep
  • Direct visibility into external caffeinate sessions
  • App-owned power assertions, so managed sessions do not outlive the app

How it works

SleepLatch uses native macOS power assertions for the sessions it manages. That means quitting or force-quitting the app clears the managed sleep blockers, which is the failure mode the plain caffeinate command leaves behind.

Install

  1. Download SleepLatch.zip.
  2. Unzip the archive.
  3. Move SleepLatch.app into Applications.
  4. Open the app and use the control window or the menu bar icon.

What you get

Timed presets

Start a short session when the network drops during sleep, without forgetting to stop it later.

Safer untimed mode

Untimed sessions require confirmation so you do not casually leave the Mac awake for hours.

External cleanup

Inspect manually launched caffeinate processes and stop them without guessing PIDs.

Minimal footprint

Small native app, no background service, no bloated dashboard, no login required.
