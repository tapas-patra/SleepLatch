Why It Exists

Built for a boring problem that kept showing up.

In local coding workflows, it is easy to kick off a task, step away, and come back to a sleeping Mac. The built-in caffeinate command works, but manual sessions are easy to forget.

SleepLatch turns that into a cleaner workflow: start a timed session, keep track of what is active, and avoid leaving sleep blockers behind longer than intended.

What It Does

Plain controls over sleep prevention.

  • Timed presets for 15 minutes, 30 minutes, 1 hour, and custom durations
  • Safer untimed sessions when you really need manual control
  • Live visibility into external caffeinate processes
  • Native power assertions for app-managed sessions

Why Not Terminal Only

Less cleanup, less guessing.

With plain caffeinate

You need to remember flags, track PIDs, and stop sessions manually.

With SleepLatch

You start a session from the menu bar, use timed presets, and clean up strays from one place.

  1. Download SleepLatch.zip.

  3. Move SleepLatch.app to Applications.
  4. Open it and use the control window or menu bar icon.

First Launch On macOS

If macOS says “SleepLatch” cannot be verified.

  1. Move SleepLatch.app to Applications before opening it.
  2. In Finder, Control-click or right-click SleepLatch.app, then choose Open.
  3. When macOS shows the warning, click Open from that dialog.
  4. If you already clicked the normal open path and got blocked, go to System Settings → Privacy & Security and click Open Anyway for SleepLatch.

This is a Gatekeeper warning for apps downloaded from the web that are not notarized by Apple. Once you approve the app, later launches should work normally on that Mac.
